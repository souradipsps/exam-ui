# SPS Exam UI

Question Bank & Teacher Management for South Point School.

## Scripts
- `npm run dev` – start dev server
- `npm run build` – production build

## Structure
- `src/pages/` – top-level screens
- `src/Components/` – reusable UI (common, layout, modals, question-bank, teacher-management)
- `src/data/` – mock data and constants
- `src/styles/` – global CSS
- `src/assets/` – images
